# @edu/ui

Дизайн-система мини-приложения (mobile-first, WebView MAX): токены, тема, базовые компоненты, иконки-заглушки и демо-страница.

## Принцип: заменяемый визуальный слой

Текущий визуал — **временный**. Финальный UI/UX делается позже и заменяется **внутри этого пакета**, не трогая потребителей:

- Только обычный CSS: `src/styles/tokens.css` (CSS custom properties) + один `.css` на компонент. Без Tailwind и CSS-in-JS.
- Классы с префиксом `ui-` (BEM-lite: `ui-button`, `ui-button__icon`). Варианты и состояния — через data-атрибуты (`data-variant`, `data-size`, `data-state`) и `aria-*`, а не через модификаторы классов.
- Компоненты не знают о домене: никаких типов из `@edu/contracts`, запросов и бизнес-логики. Только props, состояния, поведение и a11y.
- Публичный API (пропсы) стабилен и задокументирован JSDoc. Менять после foundation — только по координации с потребителями.

Пакет отдаётся исходниками (`main: src/index.ts`), сборки нет — Vite потребителя обрабатывает `.tsx` и `.css`.

## Подключение

```ts
import { Button, ToastProvider, applyTheme } from '@edu/ui';
// стили (токены + reset) импортируются один раз вместе с '@edu/ui'
```

Демо всех компонентов: `import { UiPlayground } from '@edu/ui/playground'` — монтируется web-приложением на dev-роуте.

## Тема и токены

- `applyTheme('light' | 'dark' | 'system')` ставит `data-theme` на `<html>`. Без атрибута или при `system` работает `prefers-color-scheme`.
- Цвета, типографика, отступы (сетка 4px), радиусы, тени, z-index, длительности — в `src/styles/tokens.css`. Тёмная тема переопределяет только цвета и тени.
- То, что нужно в JS (брейкпоинты, z-index, длительности), продублировано в `src/tokens.ts` — менять синхронно с CSS.
- Брендовый цвет как **цвет текста** — только через `*-text` токены: `--ui-color-primary-text`, `--ui-color-success-text`, `--ui-color-warning-text`, `--ui-color-danger-text` (AA ≥ 4.5:1 в обеих темах и на подложках тона 14%). Заливки (кнопки, чипы, графики) остаются на `--ui-color-primary`/`-success`/`-warning`/`-danger` — это цвета макета. Текст на заливках danger/info — `--ui-color-on-danger` / `--ui-color-on-info` (белый), на ярких — `--ui-color-on-bright`. Шеврон `Select` — `--ui-select-chevron` (SVG по теме).
- `color-mix()` с `var()` — только внутри `@supports (color: color-mix(in srgb, red 50%, blue))`, с запасным значением снаружи: «вторая строка» с `var()` не подстраховывает.

### Подписи для скринридера (i18n)

Пакет не знает про i18n: служебные подписи имеют русские значения по умолчанию и переопределяются пропсами — `Modal`/`Sheet`/`Drawer` `closeLabel` («Закрыть»), `PageHeader` `backLabel` («Назад»), `Toast` `closeLabel`, `ToastProvider` `regionLabel` («Уведомления») и `closeLabel` (крестик каждого тоста), `ChatComposer` `inputLabel` (по умолчанию `placeholder`, без него «Сообщение»), `sendLabel`/`stopLabel`, `BottomNavigation` `aria-label`, `Spinner`/`TypingIndicator` `label`, `ErrorState` `retryLabel`, `CodeBlock` и `Markdown` `copyLabel`/`copiedLabel`, `MonthCalendar` подписи стрелок.

### Поведение базовых компонентов

- `Text preserveLines` — сохраняет переносы строк и пробелы из текста (`white-space: pre-wrap`, `data-preserve-lines`): многострочный ввод преподавателя. Инлайн-`style` в приложении не нужен.
- `Markdown source` — безопасный Markdown без зависимостей (TEXT-блоки курса): заголовки `#`…`###` (глубже — как `###`; HTML-уровень `#` — `headingLevel`, по умолчанию h2, размер — по числу `#`), абзацы с сохранёнными переносами строк, `**жирный**`, `*курсив*` (и `_…_`, не внутри слова), `` `код` ``, блоки ```` ``` ```` через `CodeBlock` (подсветка по языку после ```` ``` ````: `python`/`py`, `cpp`/`c`/`arduino`/`ino`, `js`/`ts`), маркированные и нумерованные списки с вложенностью, цитаты `>`, линия `---`, ссылки `[текст](url)` и `<url>` (ссылка внутри подписи другой ссылки остаётся текстом: `<a>` в `<a>` не бывает). Без `dangerouslySetInnerHTML`: сырой HTML выводится текстом, ссылки — только http(s) (`target="_blank"`, `rel="noopener noreferrer"`; `onLinkClick` — свой переход, в MAX через мост), остальные схемы — просто текст, картинки — подписью (`alt`). Заголовки и блоки кода распознаются за линейное время, а просмотр вперёд при разборе ссылок ограничен бюджетом на абзац (дальше «[» — текстом): длинная строка-ловушка в тексте ИИ или преподавателя не подвешивает экран. `markdownToText(source)` — тот же текст без разметки (превью).
- `Text variant="micro"` — 10px (line-height 1.3), `<span>` по умолчанию: подписи в узких карточках (названия занятий в `DockSheet aside`, где под текст ≈110px).
- `Field group` — несколько контролов под одной подписью (чекбоксы, переключатели): корень `role="group"` с именем из подписи (`aria-labelledby`, подпись — не `<label>`), hint/error — описание группы (`aria-describedby`). id подписи в контролы не пробрасывается: у каждого `Checkbox`/`Switch` свой id (без `id` из пропсов или `Field` генерируется) и своё имя; `required` — только звёздочка у подписи, `disabled` — всем контролам. Без `group` поведение прежнее (один контрол, `<label for>`).
- `PageHeader` — заголовок до двух строк, многоточие только после второй (`-webkit-line-clamp: 2`); короткий остаётся в одну строку, высота шапки не меняется. Подзаголовок — одна строка с многоточием.
- `Chip` — `aria-pressed` только когда передан `selected` (в том числе `false`): фильтры, сегменты, пресеты сумм передают его явно; без пропа чип — обычная кнопка (подсказки-стартеры в чате).
- `ListRow onClick` — Enter/Space нажимают строку, только если фокус на самой строке: клавиши во вложенных кнопках и полях слота `right` строку не трогают. Клик по вложенной кнопке всплывает до строки — её `onClick` вызывает `event.stopPropagation()`.
- `AppLayout.Content fit` — область между шапкой и меню становится flex-колонкой «шапка экрана + `Screen`» (включается каркасом роли, сейчас — у преподавателя): `Screen fill` занимает остаток под шапкой экрана (без лишней прокрутки на её высоту), `Screen fixed` — ровно остаток и сам не прокручивается (формы с прижатыми к низу кнопками); длинную часть такого экрана кладут в `Stack scroll` — она занимает свободное место и прокручивается сама. Без `fit` раскладка прежняя, `fixed` ведёт себя как `fill`.
- `Button` / `IconButton` `loading` — `aria-busy` + `aria-disabled` вместо `disabled`: кнопка остаётся в фокусе, нажатие гасится (`preventDefault`, в том числе отправка формы submit-кнопкой и Enter в поле). `disabled` вместе с `loading` — нативно недоступна. Формы всё равно проверяют `mutation.isPending` в `onSubmit`.

Чтобы поменять внешний вид: правь значения токенов и CSS компонентов. Разметка и пропсы остаются.

## Как добавить компонент

1. `src/components/<Name>/<Name>.tsx` + `<Name>.css` + `index.ts`.
2. Компонент принимает `className` и `...rest` своего HTML-элемента; `forwardRef` для форм/кнопок/инпутов.
3. Классы `ui-<name>`, `ui-<name>__<part>`; варианты — `data-*`. CSS импортируется в самом `.tsx`.
4. Пропсы — с JSDoc на русском. Экспорт из `src/index.ts`.
5. Показать все варианты в `src/playground/index.tsx`. Тесты — только поведение/a11y (Testing Library + user-event).

Новые компоненты в пакет добавляет владелец ui (см. `docs/10-ownership.md` §10.6); до этого компонент живёт в `apps/web/src/shared/ui/`.

## Режим родителя: аналитика и задания

- `PieChart` — круговая диаграмма на SVG (по умолчанию 134px): первый сектор от «12 часов» по часовой, числа 16px внутри секторов, `explode` — сектор выдвинут на 8px по биссектрисе, легенда слева списком (квадраты 16px). Нулевые секторы пропускаются, все нули — нейтральное кольцо; `role="img"` с `aria-label` (значения перечисляет потребитель).
- `SegmentBar` — составная полоса 24px: ширины пропорциональны значениям (не уже числа), внешние концы скруглены, нулевые сегменты скрыты, все нули — пустая полоса. Список с подписями сегментов для скринридера.
- `StatusGrid` — сетка цветных ячеек (7 колонок, высота 27px, радиус 3px) для заданий: тона success / danger / warning / neutral (серый `#a4a4a4`). С `onSelect` ячейки — кнопки с одной точкой табуляции (стрелки ходят по сетке, Home/End — края), `title` — доступное имя ячейки.
- `CodeBlock` — код в стиле VS Code Dark+ (тёмный в обеих темах): моноширинный 12px без лигатур, встроенная подсветка `python` / `cpp` / `javascript` без зависимостей (ключевые слова, управление, функции, идентификаторы, числа, строки, комментарии; пропуск «\_\_\_\_» не подсвечивается), горизонтальная прокрутка, кнопка «копировать» (Clipboard API с запасным способом для WebView).
- `Band` — полупрозрачная (поверхность на 50%) полоса на всю ширину экрана (`bleed`, по умолчанию) с отступами экрана: блоки кружков в аналитике и задания в подробностях. `tone="subtle"` — полоса-заголовок над другими (курс над заданиями, макет 65:283): поверхность на 30%, ≈38px с заголовком `title`, щель 1px до следующей полосы; `flush` — вплотную к шапке экрана (снимает верхний отступ `Screen`).
- `Button variant="link"` — текстовая кнопка 14px без подложки («Подробнее»), `underline` — подчёркнутая («Скрыть»).

## Режим родителя: главная и акцент

- `applyAccent('blue' | 'green' | 'orange')` — акцент палитры на `<html>` (`data-accent`; `blue` — по умолчанию, атрибут снимается; оранжевый — см. «Режим репетитора»). Зелёный из макета родителя: primary `#0cce02`, focus `#2cda00`, свечение фона `#0dd058`; светлая тема — primary `#1a9a12`. Текст на зелёной заливке тёмный (`--ui-color-primary-contrast` = `--ui-color-on-bright`: 9.1:1 / 5.3:1; белый давал 2.1:1 / 3.7:1), иконка на круге меню остаётся белой (`--ui-color-prominent-fg`); зелёный как цвет текста в светлой теме — `#11690d` (`--ui-color-primary-text`). Токены `--ui-color-accent-1` (сердце и имя выбранного ребёнка: `#2cda00` / синий `#0264ce`) и `--ui-color-accent-2` (соседние сердца, фон переключателя периода: `#00da91` / `#1858fa`). Оболочка родителя включает зелёный при входе и возвращает синий при выходе.
- `HeartAvatar` — фото ребёнка в сердце из макета (контур 112.5×98.9, круглое фото 60% ширины по центру сердца), `tone` primary / accent / plain (белое), без фото — инициалы, `add` — плюс вместо фото.
- `HeartCarousel` — лента детей-сердец на всю ширину: выбранное по центру (112px, primary), соседи меньше (100px), бирюзовые, приподняты дугой на 40px и выглядывают у краёв экрана; последним всегда белое сердце «+» (`onAdd`; центрирование свайпом выбор не меняет). Листается свайпом со scroll-snap (по одному сердцу) и перетаскиванием мышью с докатом; размер, подъём, прозрачность и цвет каждого сердца меняются непрерывно по расстоянию до центра (rAF → CSS-переменные `--ui-heart-carousel-*`, цвет — `color-mix`), остановившееся в центре выбирается. Тап по соседу докатывает его в центр; `listbox`/`option` с roving tabindex, ←/→/Home/End без зацикливания, Tab докатывает фокусный пункт. `prefers-reduced-motion` — докрутка без анимации. Пустой список — в центре только «+».
- `WalletChip` — кошелёк в шапке: плашка с радиусом 10, `WalletIcon` цвета primary, сумма 16px и плюс; кнопка с невидимо расширенной зоной нажатия.
- `ScoopPanel` — полупрозрачная панель на всю ширину с вогнутым верхним краем (фигура «Union» из макета, кривая масштабируется по ширине); контент начинается на 12px ниже ровной середины. `grow` — до низа экрана; `overlap` — кривая заходит под блок сверху на свою глубину (как в макете: подпись выбранного сердца в ложбине); `scroll` — содержимое прокручивается внутри панели под неподвижной кривой (в `Screen fit`).
- `ProgressBubble` — круг прогресса: подпись сверху, картинка ≈55% диаметра, число и хвост («/45*») снизу; всё внутри — доли диаметра, смена `size` анимируется (`@property`). Подпись — на весь диаметр (поля 10% — только у картинки и числа): «Программирование» не рвётся ни в круге 112px, ни в 170px. `ProgressBubbleGroup` — «змейка» в две колонки, правые круги ниже на 48px, один круг — по центру.
- `SegmentedControl variant="accent"` — таблетка `--ui-color-accent-2` радиусом 20, текст 12px чёрный, выбранный — белый со «ступенькой» тени вправо («1 день / 7 дней / 30 дней»).
- `CardColumns` — `action` у колонки: полоса primary 25px «+ Добавить кружок» прямо под её карточкой (карточка снизу без скругления, у полосы скруглён правый нижний угол).
- `CardColumns` на узком экране: таблица (`variant="default"`) — контейнер по ширине (`container-type: inline-size`, ширину задаёт родитель, не содержимое); уже 380px колонки идут через 8px (к 388px плавно возвращается 16px), поля карточек 6px вместо 8px. `fit`-колонка ограничена 45% только рядом с «резиновой» колонкой; рядом с одними `nowrap` она берёт всё, что они оставят. Уже 358px (экраны уже 390px) — ещё ячейки 13px (и `Text small` в них), заголовки 14px, поля карточек 5px: на 375px «Программирование» не переносится ни у ученика и преподавателя (Название / Группа / Время), ни у родителя (Название / Репетитор / Время); от 358px таблица прежняя. На 320px — перенос по слогам (`hyphens: auto`). Проп `dense` включает то же сжатие до ширины таблицы 384px (экраны до 414px) — для трёх широких колонок, как на главной родителя, где на 390px иначе рвётся длинное название.
- Иконки из макета: `PieChartIcon` (глиф центральной кнопки меню родителя), `WalletIcon`, `HeartShapeIcon` (залитое сердце).

## Режим репетитора

- `applyAccent('orange')` — оранжевый акцент репетитора (`data-accent="orange"`): тёмная тема — primary, focus, `--ui-color-accent-1/2` `#ffa600`, свечение фона `rgba(255, 166, 0, .3)`; `--ui-color-primary-contrast` тёмный (`--ui-color-on-bright`, 9.9:1 — текст кнопок, выбранных чипов и дней на оранжевом), белая только шапочка на оранжевом круге меню (`--ui-color-prominent-fg`); светлая тема — primary/focus `#a05f00` (AA и как цвет текста: 5.1:1 на белом, 4.7:1 на фоне; белый текст на заливке), accent-1 `#d98a00`, accent-2 `#ffa600`. `ACCENTS = ['blue', 'green', 'orange']`, `getAccent` неизвестное значение читает как `blue`.
- Токены: `--ui-color-on-bright` (`#0d0d0d`, тёмный текст на ярких заливках — сумма в кошельке, «Вывести»), `--ui-color-stripe` (`#4b4545`, «зебра» строк; компонент кладёт его с прозрачностью 10%), `--ui-color-text-subtle` (`#7a7a7a` / `#636b77` — подписи дней «вчера»/«сегодня», светлее основного текста, но с контрастом AA), `--ui-color-prominent-fg` (иконка на акцентном круге `BottomNavigation`; по умолчанию = `--ui-color-primary-contrast`, у репетитора — белая).
- Иконки из макета: `GraduationCapIcon` (шапочка — центральная кнопка меню, бокс 46×46 как у `PieChartIcon`), `ClipboardListIcon` (задания, 40×40).
- `WalletChip plus={false}` — чип без плюса (у репетитора чип открывает кошелёк, а не пополнение); по умолчанию плюс есть.
- `CardColumns` (всё обратно совместимо, по умолчанию выглядит как раньше):
  - `striped` — «зебра»: строки данных подложены полосой на всю ширину карточки (≈32px у 12px-текста), у краёв карточки полоса скругляется вместе с ней; `true`/`'odd'` — 1-я, 3-я…, `'even'` — со 2-й (продолжить чередование в следующем блоке);
  - `rows[].tone` — строка подложена цветом тона на 10% (строка «Вывод» — `danger`), перекрывает полосу;
  - `variant="compact"` (кошелёк) — ячейки 12px, колонки через 7px, заголовки 11px medium приглушённые по центру колонок — отдельной строкой той же сетки над карточками (`columnheader`);
  - `showHeader={false}` — у второго и следующих блоков одной таблицы заголовки остаются только для скринридера;
  - `columns[].weight` — доля ширины `minmax(0, <weight>fr)`: блоки одной таблицы выровнены (кошелёк: 52 / 125 / 68 / 76);
  - `caption` — подпись блока 8px над линией 45px у правого верхнего угла карточек (`role="caption"`), выступает за край на 12px и не сдвигает таблицу — зазор ≈12px над блоком оставляет потребитель.
  - ARIA: DOM идёт по колонкам (subgrid), а таблица читается по строкам — обёртки колонок `role="none"`, строки `role="row"` — пустые узлы вне сетки, собирающие ячейки через `aria-owns` (заголовки, строки данных и, если есть, строка действий).
- `Illustration` — крупная картинка экрана на всю ширину контента, не шире 342px, по центру, `aspect-ratio` 342 / 256 (`ratio`), `object-fit: cover`; без `alt` — декоративная (`alt=""`, `aria-hidden`).
- `WalletHero` — кошелёк 62px цвета primary с суммой 14px внутри (длинная сумма ужимается) и под ним зелёная «чаша» 98×47 (контур из макета, цвет success, нижний край темнее — внутренняя тень) — настоящая `<button>` «Вывести» с видимым фокусом, `actionDisabled`; `aria-label` — доступное название суммы.
- `LineChart` — карточка-график (радиус 30, по умолчанию высота 111px): подписи оси Y 8px над линиями сетки у левого края, линия primary 3px со скруглёнными концами (`step` — ступенчатая: значение держится до следующей точки), подписи оси X 7px равномерно по ширине линии. Деления по умолчанию — 0 / середина / «круглый» верх (6700 → 10000); `formatTick`. SVG тянется по ширине, толщина линии не меняется (`vector-effect`). Пусто или одна точка — ровная линия. `role="img"` + обязательный `aria-label`.
- `BarChart` — карточка «Посещения» (радиус 35): легенда по курсам слева (название 12px semibold, строки «квадрат 14px + подпись», `dim` — темнее), составные столбцы 28px (ужимаются, если не влезают) со скруглённым верхом 10px: части снизу вверх, `dim`-часть — тот же цвет темнее (яркость × 0.72: `#ffa600` → `#b87700`), итог над столбцом 7px semibold (по умолчанию сумма), подпись под столбцом (код группы) — не шире шага столбцов, длинная обрезается многоточием; подписи-строки длиннее 5 символов (название группы без кода) раздвигают столбцы по центру равных долей ширины (`data-spread`), и подпись занимает свою долю — соседние не наезжают. Тона — `primary` или `Tone`. Деления по умолчанию — 0 / половина / максимум, округлённый вверх до десятка. Нулевой столбец — пустое место с подписью. `role="img"` + `aria-label` со значениями.
- `DataTable` — настоящая `<table>`: заголовки 11px medium приглушённые над карточкой, тело — одна карточка поверхности (радиус 20), строки 44px, значения 12px medium, перенос — по словам, слово шире колонки — по слогам (`hyphens: auto`); `columns[].weight` (доли ширины), `align`, `tone` (цвет значений колонки); `caption` — визуально скрытая подпись. Строка с `onClick` кликабельна целиком: мышь/палец — по любому месту, клавиатура и скринридер — кнопка в первой ячейке (`rows[]['aria-label']`), фокус — рамка вокруг всей строки.
- Демо — `TutorDemo` в playground (переключатель акцента — в демо родителя, вариант «Оранжевый — репетитор»).

## Режим ученика: экран без скролла, чаты, свёртка (2026-09-28)

Все пропсы необязательные, по умолчанию поведение прежнее.

- `Screen fit` — экран ровно в высоту скролл-области: дети не растягивают её, свободное место забирает гибкий ребёнок, а при нехватке сжимаются дети со `Stack scroll` (главная ученика).
- `Stack scroll` — блок сжимается под доступное место в родителе-flex и прокручивает содержимое сам (`min-height: 0; overflow-y: auto`).
- `IllustrationRow fluid` — высота ряда — сколько осталось в родителе-flex (не больше 259px, вплоть до нуля), картинки вписываются в неё.
- `Drawer side="left"` — панель у левого края колонки контента, въезжает слева (история чатов тьютора).
- `PageHeader leading` — действие слева, после «Назад» (кнопка истории чатов).
- `ChatBubble appear` — плавное появление при монтировании (подъём 8px + проявление, 1.5 × `--ui-duration-normal`; при `prefers-reduced-motion` без анимации) — для новых сообщений ленты, не для истории.
- Иконки: `MenuIcon` (история/меню), `EditIcon` (новый чат), `ChevronDownIcon` / `ChevronUpIcon` (раскрыть / свернуть).

## Демонстрационный режим: тур (2026-09-29)

- `Coachmark` — шаг обучающего тура: экран затемнён, цель подсвечена «окном» с обводкой primary (`target` — прямоугольник из `getBoundingClientRect()`; `null` — карточка по центру), рядом карточка со стрелкой: `eyebrow` (раздел), заголовок цвета primary, текст (`children`), крестик и подвал «Назад / Завершить» · «N/M» · «Далее / Готово». Портал в body, слой `--ui-z-coachmark` (250: над модалками, под тостами); клики по приложению ловит «щит», с `interactive` — всё, кроме «окна» (подсвеченное можно потрогать). Карточка под целью, если влезает, иначе над ней, иначе у края `overlaySide` (`bottom` по умолчанию, `top` — у чата) поверх подсветки. «Окно» есть всегда (без цели сжато в точку), поэтому переходы между шагами анимируются. Клавиши на документе: Escape — `onClose`, → — `onNext`, ← — `onPrev` (не на первом шаге), при вводе в поле — не срабатывают; фокус — на «Далее», Tab зациклен. `busy` — переход к шагу: затемнение и спиннер (появляется через 300 мс), стрелки не листают. Позицию цели считает и обновляет потребитель (прокрутка, ресайз). Подписи — пропсами (`nextLabel`, `prevLabel`, `doneLabel`, `endLabel`, `closeLabel`, `counterLabel`, `busyLabel`). Демо — `CoachmarkDemo` в playground.
