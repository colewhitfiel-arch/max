# Приложение для дополнительных занятий в школах

Приложение предназначено для организации дополнительных кружков и занятий в школах, контроля посещаемости, выполнения заданий и индивидуального прогресса учеников.

Приложение работает как мини-приложение внутри мессенджера MAX.

В системе предусмотрены четыре типа пользователей:

1. Ученик.
2. Родитель.
3. Репетитор / преподаватель кружка.
4. Четвёртая роль будет проработана отдельно.

Все роли работают с одной системой и общими данными. Информация о занятиях, заданиях, посещаемости и прогрессе ученика автоматически отображается у связанных пользователей.

---

# 1. Версия для ученика

Основная задача приложения для ученика — помочь выбрать подходящие дополнительные занятия, организовать обучение и показать личный прогресс.

## Онбординг

При первом запуске ученик проходит онбординг.

Вместо стандартной анкеты основная часть онбординга проходит в формате диалога с ИИ-тьютором.

ИИ задаёт вопросы:

- чем ученик интересуется;
- какие предметы ему нравятся;
- какие навыки он хочет развить;
- какие у него цели;
- сколько времени он готов уделять дополнительным занятиям;
- какие форматы занятий ему подходят.

На основании ответов GigaChat формирует первичный профиль ученика и предлагает подходящие кружки и дополнительные занятия.

После выбора кружков ученик попадает в основное приложение.

## Нижнее меню ученика

В приложении пять основных разделов:

1. Главная.
2. ИИ-тьютор.
3. Задания и курсы.
4. Настройки.
5. Профиль.

## 1.1. Главная

Главный экран должен быстро отвечать ученику на три вопроса:

### Что у меня сегодня?

Показываются ближайшие занятия и календарь.

### Что мне нужно сделать?

Показываются ближайшие задания, дедлайны и незавершённые активности.

### Как у меня идут дела?

Показывается краткая аналитика:

- посещаемость;
- выполнение заданий;
- активность;
- прогресс по выбранным кружкам.

На главном экране также может отображаться короткий персональный комментарий от ИИ:

> За последние две недели ты посетил все занятия по робототехнике, но осталось два задания по программированию.

## 1.2. ИИ-тьютор

Отдельный полноценный чат с GigaChat.

ИИ имеет доступ к учебному контексту конкретного пользователя:

- выбранным кружкам;
- расписанию;
- заданиям;
- выполненным заданиям;
- посещаемости;
- целям;
- личной образовательной траектории.

Ученик может писать обычным языком:

- «Что мне сегодня нужно сделать?»
- «Какой кружок мне лучше выбрать?»
- «Я хочу научиться программировать».
- «Почему у меня упал прогресс?»
- «Что мне пройти дальше?»
- «Помоги разобраться с заданием».

ИИ используется как постоянный персональный помощник ученика.

## 1.3. Задания и курсы

Здесь ученик видит все свои кружки и курсы.

Например:

- Робототехника.
- Английский язык.
- Программирование.
- Шахматы.

После открытия конкретного курса ученик видит его структуру.

Внутри могут находиться:

- текстовые материалы;
- видео;
- изображения;
- файлы;
- тесты;
- вопросы;
- практические задания;
- домашние задания;
- интерактивные упражнения.

Система фиксирует действия ученика:

- какие материалы открыты;
- какие блоки пройдены;
- какие задания выполнены;
- результаты заданий;
- дату выполнения;
- количество попыток;
- прогресс по курсу.

Эти данные затем используются в аналитике преподавателя.

Система формирования таких курсов преподавателем будет отдельным большим модулем.

## 1.4. Настройки

В настройках ученик может:

- выбрать тему приложения;
- сменить роль;
- обратиться в поддержку — кнопка открывает чат поддержки в MAX (адрес чата — настройка развёртывания `VITE_SUPPORT_URL`, общая для всех ролей: та же кнопка — в настройках родителя и преподавателя; адрес не задан — подсказка, что чат пока не подключён).

Выбора языка и настроек уведомлений у ученика нет (2026-09-28: убраны по запросу владельца продукта).

## 1.5. Профиль

В профиле отображаются:

- аватар;
- имя / ник;
- учебная группа;
- выбранные кружки;
- процент посещаемости;
- процент выполнения домашних заданий;
- общая активность.

Отдельный блок — **«Моя траектория»**.

GigaChat периодически формирует персональную образовательную траекторию на основании данных ученика.

Например:

> Тебе хорошо даются задания, связанные с логикой и программированием. За последний месяц ты стабильно выполняешь задания по робототехнике. Следующим шагом можно попробовать более сложный курс по Python.

Траектория обновляется по мере накопления новых данных.

# 2. Версия для родителей

Основная задача родительского приложения — дать родителю полную картину того, как ребёнок занимается дополнительным образованием.

После входа родитель выбирает привязанного ребёнка.

Если детей несколько, между их профилями можно переключаться.

## Главный экран

Родитель видит:

- сегодняшние занятия ребёнка;
- ближайшие занятия;
- пропущенные занятия;
- новые задания;
- просроченные задания;
- краткую динамику обучения.

## Аналитика ребёнка

Отдельный экран содержит подробную информацию:

- посещаемость;
- количество пропусков;
- выполнение домашних заданий;
- прогресс по каждому кружку;
- активность;
- результаты заданий;
- динамику за определённый период.

Также может отображаться сформированное ИИ краткое резюме:

> За этот месяц посещаемость составляет 92%. Большинство заданий выполняются вовремя. Наибольший прогресс наблюдается в робототехнике.

## Кружки

Родитель видит список кружков ребёнка.

Для каждого кружка показываются:

- название;
- расписание;
- преподаватель;
- описание;
- стоимость;
- прогресс ребёнка.

## Преподаватель

Родитель может открыть карточку преподавателя и увидеть:

- фотографию;
- имя;
- квалификацию;
- описание;
- кружки;
- контактную информацию, если школа разрешает её отображение.

## Оплата

В приложении можно оплачивать дополнительные занятия.

Родитель видит:

- стоимость;
- оплаченный период;
- следующую дату оплаты;
- историю платежей.

# 3. Версия для преподавателя

Главная задача преподавательской версии — управление учениками, заданиями и образовательным контентом.

## Главный экран

Преподаватель видит (макет «режим репетитора», docs/07 F16):

- расписание дня по всем своим группам — кружок, номер группы, время; текущее занятие выделено; другие дни — стрелками и календарём месяца;
- баланс кошелька (→ кошелёк: поступления, вывод, «Вам должны», docs/07 F17);
- уведомления (важные события).

Остальное вынесено с главной: задания, которые нужно проверить, — вкладка «Задания» нижнего меню (`/teacher/assignments`); группы — в настройках и профиле; краткая статистика (группы, ученики, посещаемость, «требуют внимания») — в профиле; успеваемость групп — центральная кнопка меню «Успеваемость» (docs/07 F18).

## Группы

Преподаватель видит свои кружки и группы.

После открытия группы отображаются:

- список учеников;
- посещаемость;
- выполнение заданий;
- общий прогресс;
- ученики, которым требуется внимание.

Можно открыть конкретного ученика.

## Успеваемость ученика

Преподаватель видит по своим группам ученика (docs/07 F18):

- посещения за неделю;
- домашние задачи: правильно, неправильно, предстоит;
- по каждому кружку — итоги и сетку заданий;
- задания: условие, ответ ученика и правильный ответ.

Сейчас в интерфейсе преподавателя **не выводятся** (отложено, не отказ; поля в DTO остаются, задача — docs/12 «Состояние»): история выполненных заданий, динамика, активность, причины «требует внимания» и краткое резюме GigaChat, например:

> Ученик регулярно посещает занятия, но последние три задания выполнял после дедлайна.

## Система создания заданий и курсов

Это один из ключевых модулей приложения.

Преподаватель может создавать образовательные материалы несколькими способами.

### Вариант 1. Простое задание

Преподаватель пишет:

> До пятницы решить задачи 1–10 на странице 52.

Система создаёт стандартное домашнее задание.

### Вариант 2. Загрузка материалов

Преподаватель загружает:

- документ;
- презентацию;
- методичку;
- фотографии;
- текст;
- другие учебные материалы.

После этого материалы проходят через автоматический пайплайн.

Система:

1. Анализирует загруженные материалы.
2. Определяет структуру и темы.
3. Делит материал на логические блоки.
4. Генерирует понятную структуру курса.
5. Создаёт задания и контрольные вопросы.
6. Формирует интерактивные элементы.
7. Показывает результат преподавателю.
8. Преподаватель редактирует его при необходимости.
9. Публикует курс ученикам.

В результате преподавателю достаточно предоставить исходные материалы, после чего система помогает превратить их в структурированный цифровой курс.

Этот модуль требует отдельной детальной проработки.

# 4. Общая логика системы

Центральным объектом приложения является ученик.

К ученику привязываются:

- родитель;
- преподаватели;
- группы;
- кружки;
- занятия;
- задания;
- курсы;
- результаты;
- посещаемость;
- платежи;
- персональная траектория.

Любое действие обновляет связанные данные.

Например:

- ученик выполнил задание;
- результат появился у преподавателя;
- обновился процент выполнения;
- обновилась аналитика родителя;
- новые данные могут использоваться ИИ для изменения персональной траектории.

Другой пример:

- преподаватель отметил посещение;
- обновилась статистика ученика;
- родитель видит новое значение;
- GigaChat получает эту информацию как часть контекста.

---

# 5. GigaChat

GigaChat используется как общий интеллектуальный слой приложения.

Он отвечает за:

- онбординг ученика;
- подбор кружков;
- чат с учеником;
- формирование персональной траектории;
- краткие выводы по аналитике;
- помощь преподавателю в создании курса;
- обработку образовательных материалов;
- генерацию заданий;
- объяснение результатов пользователям.

Основные показатели — посещаемость, выполнение заданий, результаты и платежи — рассчитываются системой на основании фактических данных.

---

# 6. Общая идея продукта

Приложение связывает четырёх участников дополнительного образования в одной системе.

**Ученик** получает понятное расписание, задания, персонального ИИ-тьютора и собственную траекторию развития.

**Родитель** получает прозрачную аналитику обучения ребёнка и возможность управлять оплатой занятий.

**Преподаватель** получает инструменты контроля учеников и систему быстрого превращения собственных материалов в цифровые курсы.

Все версии работают поверх единой базы данных внутри мини-приложения MAX.
