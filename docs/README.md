# Документация проекта (source of truth)

Мини-приложение для дополнительного образования в школах внутри мессенджера MAX. Роли: ученик, родитель, преподаватель, четвёртая — позже. Интеллектуальный слой — GigaChat.

Эта папка — единственный источник правды по архитектуре. Правило: **сначала правим документ, потом код**. Если код расходится с документом — прав документ через владельца (см. `10-ownership.md`), затем код.

## Открытые вопросы (нужен ответ продукта, не блокируют старт)

1. **Четвёртая роль** — предположительно «администратор школы» (`SCHOOL_ADMIN`). Зарезервирована в enum, экраны не проектируются.
2. **Как ученик/преподаватель попадают в школу.** Принято: преподаватель — по коду приглашения школы; ученик — свободная регистрация + код школы (опционально); массовый импорт — позже.
3. **MAX Bridge.** Точный API launch-параметров и проверки подписи сверить с dev.max.ru. Заложен адаптер, в dev — заглушка.
4. **Платёжный провайдер.** По умолчанию ЮKassa через порт `PaymentProvider`. Если у MAX есть встроенные платежи — меняется только адаптер.
5. **Push через MAX** (бот/API) — уточнить возможности. MVP: in-app уведомления.
6. **Курс привязан к группе**, не к кружку. Переиспользование курса между группами — копированием (v2).
7. **Данные детей** (152-ФЗ, согласие родителя) — юридический вопрос. Технически заложены минимизация контекста для ИИ, флаг видимости контактов, аудит.
8. **Распределение ученика по группам кружка** после онбординга: MVP — первая активная группа; назначение преподавателем — v2.
- `13-course-pipeline.md` — пайплайн course-builder на GigaChat: атомы, узлы знаний с цитатами, уроки; режим «по теме без конспекта».
