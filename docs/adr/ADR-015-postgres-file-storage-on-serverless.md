# ADR-015. Файлы в Postgres на serverless-стенде без S3

Дата: 2026-09-30. Статус: принят. Дополняет ADR-014 (п. 5 «Файлы — S3») и ADR-012 (локальное хранилище).

## Контекст

Главный сценарий продукта — преподаватель загружает конспект, ИИ собирает из него курс. На живом
стенде Vercel он не работал: бакета S3 у стенда нет, а `STORAGE_DRIVER=local` на serverless
бессмыслен — у инстансов функции нет общего диска (`/tmp` у каждого свой и живёт, пока жив
инстанс). Файл, загруженный запросом `PUT /files/local/:token` в один инстанс, не видели ни
`confirm`, ни пайплайн course-builder в другом. Режим «по теме» работал, «из конспекта» — нет.

Заводить внешний S3 для демо-стенда — ещё один аккаунт, ключи и CORS; база (Neon) у стенда уже есть.

## Решение

1. Третий драйвер порта `StorageProvider` — `PostgresStorage` (`STORAGE_DRIVER=postgres`):
   байты лежат в таблице `stored_objects` (`key` PK = `storageKey`, `data bytea`, `contentType`,
   `sizeBytes`). Ни один модуль не читает таблицу напрямую — только через порт.
2. Загрузка и скачивание идут через api по подписанным ссылкам `PUT/GET /files/local/:token`,
   как у `LocalFsStorage`: общая логика токенов (HMAC, срок, операция, заявленные тип и размер)
   вынесена в базовый класс `SignedLinkStorage`, наследники отличаются только тем, где байты.
3. На Vercel (`apps/api/src/vercel.ts`) драйвер выбирается сам: всё, кроме явного `s3`, —
   `postgres` (`serverlessStorageDriver`). Локальный диск там не работает никогда, поэтому
   переменная окружения стенда не может оставить его сломанным.
4. dev и Docker по умолчанию остаются на `local`; прод с объёмами — `s3` (ADR-014 п. 5).

## Последствия

- Загрузка конспектов, извлечение текста и сдачи с файлами работают на бесплатном стенде без
  внешних сервисов; интеграционный тест полного сценария (`full-scenario.test.ts`) идёт на
  `STORAGE_DRIVER=postgres`.
- Размер файла ограничен телом запроса функции (на Vercel ~4,5 МБ) — конспектам и фото решений
  хватает; видео и большие pdf — только через S3.
- Байты занимают место в базе (Neon free — 0,5 ГБ): для стенда приемлемо, для продакшена — S3.
- Миграция `20260930120000_password_auth_and_db_storage` добавляет таблицу; на серверах с `local`
  и `s3` она просто пустует.
