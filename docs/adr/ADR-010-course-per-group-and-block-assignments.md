# ADR-010. Курс привязан к группе; задания из блоков создаются при публикации

**Статус:** accepted, 2026-09-21

## Контекст
В продукте есть два вида «заданий»: простое домашнее задание текстом («решить 1–10 до пятницы») и задания внутри структуры курса (тест, вопрос, практика, ДЗ). Ученик, родитель и аналитика должны видеть их одним списком с дедлайнами и статусами. Курс генерируется из материалов преподавателя под конкретную аудиторию.

## Решение
- `Course.groupId` обязателен: курс принадлежит группе (а не кружку). Переиспользование — копированием (v2).
- Единая сущность `Assignment` для обоих видов. Простое задание: `courseId = blockId = null`. Задание из курса: `blockId` уникален.
- При `publish` курса преподаватель задаёт дедлайны для блоков-заданий; `courses` публикует `course.published`, `assignments.createFromBlocks` создаёт `Assignment` на каждый блок типа QUIZ/QUESTION/PRACTICE/HOMEWORK.
- `POST /student/blocks/:id/complete` для блока-задания делегирует в `assignments.submitFromBlock`, так что `Submission` — единственный источник результата; `BlockProgress` отражает прохождение.
- После публикации структура заморожена (MVP): правки только текста блоков (`PATCH /teacher/blocks/:id`). Изменение структуры — архив + новый курс.

## Последствия
- Один список заданий, одни формулы выполнения для всех ролей.
- `courses → assignments` — единственная горизонтальная зависимость в слое; обратной нет.
- Версионирование курсов и переиспользование между группами откладываются, но модель (`version`, `groupId`) их не блокирует.
