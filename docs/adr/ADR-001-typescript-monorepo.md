# ADR-001. TypeScript-монорепо на pnpm + Turborepo

**Статус:** accepted, 2026-09-21

## Контекст
Три роли в одном мини-приложении, backend с ИИ-пайплайнами, разработка параллельными агентами. Главный риск — рассинхрон типов между фронтом и бэком и конфликты правок.

## Решение
Один язык (TypeScript, Node 22) для web, api, worker и пакетов. Монорепо: `apps/{web,api}`, `packages/{contracts,db,ai,ui,config}`. pnpm workspaces + Turborepo.

Альтернатива (Python/FastAPI для бэка из-за ИИ/парсинга документов) отклонена: теряется общий пакет контрактов, добавляется второй тулчейн для агентов; парсинг pdf/docx/pptx в Node достаточен для MVP.

## Последствия
- Типы API и события — один пакет, потребляется обеими сторонами.
- Один lint/test/CI пайплайн.
- Если позже понадобится Python для ML — выносится отдельным сервисом за очередью, контракт остаётся в `packages/contracts` (OpenAPI-экспорт).
