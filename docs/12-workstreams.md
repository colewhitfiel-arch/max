# 12. Workstreams после foundation

Foundation завершён (`docs/FOUNDATION.md`). Ниже — независимые направления для параллельных агентов. Перед стартом каждый читает `docs/AGENT_GUIDE.md`. Общие правила для всех workstream'ов:

- **Контракт** для домена уже описан в `packages/contracts/src/routes/<domain>.ts` — реализуй его; менять формы можно только добавлением полей (иначе координация с владельцем contracts и FE-потребителями).
- **Не трогать:** `apps/api/src/common/**`, `apps/api/src/app.module.ts`, `apps/web/src/app/**`, `apps/web/src/shared/**`, `packages/db/prisma/migrations/**`, `packages/db/prisma/schema/base.prisma`, `packages/contracts/src/{index,enums,errors,events,permissions}.ts`, `packages/ui/**`, корневые конфиги. Нужна правка там — запрос владельцу (одна строка в `modules/index.ts`, `router.tsx`, `bottom-nav.config.ts`, `handlers/index.ts` — норма).
- **Можно использовать:** `AiService` (DI), `STORAGE`, `JOB_QUEUE`, `KV_STORE`, `DomainEventBus`, `PrismaService`, `Errors`, `@CurrentUser/@Roles/@RequirePermission`, публичные сервисы `IdentityService`, `SchoolService`, `FamilyService`; во фронте — `api`, `unwrap`, хуки `shared/auth`, `useMaxBridge`, компоненты `@edu/ui`.
- **Критерий завершения (общий):** контракт домена реализован (нереализованные ручки отдают `Errors.notImplemented`, а не 404); интеграционные тесты на ручки и policies (403 на чужой ресурс); экраны работают в `VITE_API_MODE=real` и `mock`; `pnpm lint && pnpm typecheck && pnpm test && pnpm build` зелёные; `docs/04`/`docs/05` обновлены при изменениях; seed-фрагмент добавлен, если нужны данные.

## Состояние (2026-09-21)

- **G** — реализовано: `files` (upload-url/confirm/get, локальные ссылки, извлечение txt/md/pdf/docx), `course-builder`
  (пайплайн атомы → узлы → уроки на GigaChat, режим «по теме без конспекта», ревью и accept, экраны преподавателя,
  MSW-моки, интеграционные тесты). Не сделано: редакторы блоков на клиенте, pptx/OCR, S3-адаптер. Детали — `13-course-pipeline.md`.
- **C** — реализовано: онбординг-диалог с подбором кружков («записаться» / «попробовать позже»; выбор фиксируется как спрос
  `StudentClubInterest`, диалог знакомства становится чатом тьютора; отчёт `GET /teacher/clubs/demand` и экран
  `/teacher/clubs/demand`), тьютор (SSE, контекст ученика с «хочу позже», дневной лимит),
  траектория (job, sourceHash, ручной refresh раз в сутки), экран онбординга, виджет траектории. Не сделано: инсайты
  (`AiInsight`) для главной/родителя/преподавателя.
- Минимальные публичные сервисы для зависимостей: `GroupsService` (E), `CatalogService` (D), `CoursesService.createFromDraft` (B) —
  владельцы workstream'ов расширяют их, не ломая сигнатуры.

## Порядок запуска

1. **E** первым (policies групп нужны почти всем), параллельно **A** (формулы/дашборды по seed), **G** (files + пайплайн), **J**, **K**, **L**.
2. Затем **B**, **H**, **D**, **I** (ждут только интерфейсы E; FE — сразу на моках).
3. **C** и **F** — после первых данных от A/B (FE можно раньше на моках).

## Единые интерфейсы, которые должны оставаться стабильными

`AuthUser`, декораторы auth, `Errors.*`/`ApiError`, `DomainEventSchemas`, `JobQueue`/`KeyValueStore`/`StorageProvider`/`AiProvider` порты, пути и ключи роутов контракта, `MaxBridge`, хуки `shared/auth` и `shared/api` во фронте, пропсы компонентов `@edu/ui`. Их изменение — только через владельца и с уведомлением всех workstream'ов.
